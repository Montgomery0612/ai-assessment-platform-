## 预期结果

标准化公式为 `(平均分 - 1) / 4 × 100`。
所有展示分数保留 10 位小数；前端展示时再统一格式化。

| 输出 | 手算 | 预期 0–100 分 |
| --- | --- | ---: |
| 外向性 | `(5 + 2) / 2 = 3.5` | 62.5 |
| 宜人性 | `(4 + 4) / 2 = 4` | 75 |
| 尽责性 | `(4 + 5) / 2 = 4.5` | 87.5 |
| 神经质 | `(2 + 3) / 2 = 2.5` | 37.5 |
| 开放性 | `(5 + 3) / 2 = 4` | 75 |
| AI 信任 | `4` | 75 |
| 审慎使用（描述性） | `5` | 100 |
| AI 担忧（返回值为积极方向，越高代表越不担忧） | 原始均值 `(5 + 3) / 2 = 4`；反向为 `6 - 4 = 2` | 25 |
| 使用意愿 | `(5 + 4 + 2) / 3 = 3.6666666667` | 66.6666666667 |
| AI 社会影响看法 | `(2 + 5) / 2 = 3.5` | 62.5 |
| 总体积极态度 | `(4 + 2 + 3.6666666667 + 3.5) / 4 = 3.2916666667 → 标准化` | 57.2916666667 |

总体积极态度先对四个分量表的原始均值做等权平均：信任、反向后的担忧、使用意愿、社会影响看法；随后统一标准化为 0–100。标准化是线性变换，因此先平均后标准化与先标准化后平均在本项目中等价。审慎使用与 `ai_10` 均不进入总分。

总体分使用未舍入的中间均值计算，与由展示分量表复原的结果可能有极小浮点差异。
